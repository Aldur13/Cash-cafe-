# 14 — Keyboard Shortcuts

The counter flow is designed so a whole purchase can be done without the mouse.
Print this page and tape it next to the till.

## The main flow

| Key | Does |
|---|---|
| *(just start typing)* | Search for a student — the box already has focus |
| `↓` `↑` | Move through the drop-down list |
| `Enter` | Choose the highlighted student / item, then move to the next field |
| `Tab` | Next field |
| `Shift+Tab` | Previous field |
| `Enter` (on a filled purchase) | **Execute** |
| `Ctrl+Enter` | Execute from anywhere on the screen |
| `Esc` | Clear the whole purchase and start again |
| `Backspace` (in an empty item row) | Go back to the previous row / the student box |

## Item rows

| Key | Does |
|---|---|
| *(a letter, with the drop-down closed)* | Jump to the first item whose name starts with it |
| `+` / `-` | Quantity up / down |
| `0`–`9` (in the Qty field) | Type a quantity |
| `Ctrl+Delete` | Remove the current row |
| `Ctrl+↓` | Jump to the next item row |

## Screens

| Key | Does |
|---|---|
| `F1` | Help — opens this wiki |
| `F4` | Deposit |
| `F5` | Refresh students and items (after an admin changed something) |
| `F9` | Admin panel (asks for the PIN) |
| `Ctrl+Shift+F9` | Admin panel in kiosk mode, where the button is hidden |
| `F11` | Full screen |
| `Esc` (in Admin) | Back to the Café screen |

## Corrections

| Key | Does |
|---|---|
| `Ctrl+Z` | Undo the last purchase from this session (within 15 minutes) |
| `Ctrl+L` | Focus the **Last purchases** list |

## In lists and reports

| Key | Does |
|---|---|
| `Ctrl+F` | Search the list |
| `Ctrl+E` | Export the current view to Excel |
| `Ctrl+P` | Print the current view |
| `Ctrl+N` | New (student, item or deposit, depending on the tab) |

## Speed run

An experienced user serving Carl a toast and two juices:

```
c a r ⏎        student
t ⏎            Toast
j ⏎ + +        Juice, quantity 2
⏎              Execute
```

Eleven keystrokes, about four seconds, no mouse.
